## 🌊 About This Project

This repository contains the source code for our Valheim server landing page, hosted using **GitHub Pages**.

The page provides a simple way for friends and fellow Vikings to launch Valheim and connect directly to our dedicated server.

**Live Website:**  
https://git-hub-wasabii.github.io/valheim-connect/

## 🚢 How to Join

1. Visit the [Valheim Kampung Server landing page](https://git-hub-wasabii.github.io/valheim-connect/).
2. Click **Sail to Our Island**.
3. Allow your browser to open Steam and launch Valheim.
4. Select your character.
5. Enter the server password when prompted.
6. Welcome to the kampung!

## 🛠️ Built With

- HTML5
- CSS3
- Steam URI Protocol
- GitHub Pages

No frameworks, databases, or backend services required. Just a simple static webpage.
